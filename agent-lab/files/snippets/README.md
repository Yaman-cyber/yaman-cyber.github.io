# Agent Lab · code snippets

Every code example from the **Agent Lab** course, one file per lesson, in course order.

- `module-00/` … `module-13/`, then `module-capstone/`
- File names follow the lessons: `lesson-05-put-it-together-the-loop.js` is Module 01, Lesson 5.
- The first line of each file is the label shown above the code in the lesson (for example `// agent.js` or `// terminal`). The rest is the code exactly as it appears in the course.

Read the lessons at https://yaman-cyber.github.io/agent-lab/ (each module has its own page, for example `/agent-lab/m3/` for Module 03).

These are the lessons' code exactly as shown, so most snippets build on earlier ones and don't run alone. For runnable code, download from the same page:

- `docbot-modules-00-11.zip`: every lesson file from Modules 00–11 in its real place, ready to run.
- `docbot-starter.zip`: the finished project from Modules 12–13, with the sample documents and eval set.
