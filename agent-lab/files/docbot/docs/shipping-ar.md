# الشحن والتوصيل

## مدة التوصيل (الإمارات)
- دبي، أبوظبي، الشارقة: 2–3 أيام عمل، أو اليوم التالي مع الشحن السريع.
- باقي الإمارات: 3–5 أيام عمل، أو يومين مع الشحن السريع.

## رسوم الشحن
- الشحن العادي **مجاني** للطلبات فوق **200 درهم**، وتحتها بيكلف 15 درهم.
- الشحن السريع بيكلف **35 درهم** على أي طلب.

## التتبّع
بيوصلك رابط تتبّع بالإيميل والـ SMS لما ينشحن طلبك.
