Learn to build AI agents, one small idea at a time.

From zero to a real agent in plain JavaScript. Every lesson is one idea, a short explanation, and an example. Every module adds a feature to one project: DocBot, an assistant that answers questions from your documents.

  • 00 · Start here: What AI models are, and how to talk to one from code.
  • 01 · Tools and the agent loop: Let the AI ask your code to do things.
  • 02 · Structured outputs: Get data back in a shape your code can trust.
  • 03 · Embeddings and vector search: Search by meaning, not by exact words.
  • 04 · RAG: answer from your docs: Find the right pieces, then answer with sources.
  • 05 · Evals: testing AI: Prove a change made things better, instead of guessing.
  • 06 · Observability: See exactly what your agent did, step by step.
  • 07 · LangGraph.js: Agents you can pause, resume and control.
  • 08 · MCP: Build a tool once, use it in any AI app.
  • 09 · Memory: Remember users across conversations.
  • 10 · Sandboxing: Let the AI run code without risking your computer.
  • 11 · Prompt injection defense: When the text your agent reads tries to give it orders.
  • 12 · Code structure and refactoring: Turn a folder of experiments into a codebase you can grow.
  • 13 · DocBot in a real app: Expose the agent through an API, live chat, and tools that call real systems.
  • ★ · Capstone: ship DocBot: Put every layer together into one real product.
